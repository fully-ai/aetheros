# AetherOS Testing & Verification Report

## 1. Automated Verification Architecture (`./scripts/test.sh`)

Per Project Rule 0.2, every test result documented in AetherOS is generated by actual execution of `./scripts/test.sh`, which runs:
1. **Stage 1 — Host Workspace Unit & Fuzz Tests (`cargo test --workspace`)**: 14 unit and fuzz smoke tests across `aether-abi`, `aether-uuid`, `aether-elf`, and `aether-fs-core`.
2. **Stage 2 — Release Build & Hybrid GPT Disk Image Construction**: Compiles all Ring 3 ELF64 binaries (`userspace/`), packs `build/initramfs.tar`, compiles the higher-half `x86_64` kernel (`build/aetheros.elf`), and creates a 64 MiB UEFI+BIOS hybrid GPT disk image (`build/aetheros-test.img`).
3. **Stage 3 — Automated QEMU UEFI (OVMF) & Legacy BIOS Self-Tests**: Boots `build/aetheros-test.img` in `qemu-system-x86_64` under **both** UEFI (`edk2-x86_64-code.fd`) and Legacy BIOS, executes all 19 in-kernel and Ring 3 test suites (`kernel/src/selftest.rs`), and verifies QEMU exits via `isa-debug-exit` with status `33` (`PASS`) and `[AETHEROS-TEST] ALL MILESTONE 1 - 14 KERNEL, USERSPACE & GUI TESTS PASSED`.
